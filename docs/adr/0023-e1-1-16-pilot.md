## Decision

1. **Scope.** K=1, no recursion, no trellis. Trellis remains E1b. E1a, the 1/4
   run and E2–E4 stay behind their own gates. The open 1/4 tokenizer choice
   does not block this pilot.
2. **Arms and seeds.** Four arms, seeds 0, 1 and 2, paired across arms: scalar
   ternary, scalar 2-bit, VQ-seed, and learned VQ with one shared book. The
   scalar recipe is copied from the stored `94847b` decisions, not from a
   submitted repair width. `n_heads` stays `d / 16`.
   - Ternary: `d` 80, 4 layers, `n_heads` 5, nominal `d_ff` 262, SwiGLU,
     `row8log`, `emb_fmt` `4bit`, delta 0.5, `qk_norm` false, vocab 256,
     context 256, lr 0.01, wd 0.1.
   - 2-bit: `d` 96, 3 layers, `n_heads` 6, nominal `d_ff` 193, SwiGLU,
     `row8log`, `emb_fmt` `4bit`, delta 0.5, `qk_norm` false, vocab 256,
     context 256, lr 0.003, wd 0.1. Submitted `d_ff` 205 is not copied.
3. **Books.** A learned book at 1/16 may only be one of the rows the fit table
   marks inside the ceiling: shared G=8 at rate 0.5, shared G=8 at rate 0.75,
   or shared G=16 at rate 0.5. Per-matrix G=16 books and the 4096×16 fp16 book
   are excluded. The pilot default is shared G=8. Both rates, 0.5 and 0.75,
   are trained at that G. Shared G=16 at rate 0.5 may replace G=8 only by an
   edit of this ADR before the first scientific attempt. Alphabet size is
   `2 ** (G * rate)`. VQ-seed uses the same G and rate as the learned arm
   beside it and stores the generator seed instead of the entries.
4. **Equal coded bytes.** The target is 85937.5 bytes. Every arm's packed
   file must pass the ADR 0020 window: each serialized size within ±1% of that
   target. The reciprocal check `max/min − 1 ≤ 0.01` is not a rule. Learned-book
   bytes are inside that file. A seed book contributes no entry bytes. Before
   the first training attempt, one init-pack `d_ff` adjustment is allowed
   under [ADR 0019](0019-host-init-pack.md). After training, one S3 width
   repair is allowed under the repair rule of campaign `94847b`. Neither
   repair changes G, rate, or the book length.
5. **Tokens.** T is 20 times the stored-parameter count of the largest arm.
   Every arm sees that same token count, with cooldowns at T, 2T and 4T.
   Saturation is recorded and is not a gate.
6. **Data.** The frozen E0 TinyStories split, byte tokenizer V=256, context
   256, tied 4-bit embedding, fp16 norms. BPE is not used. Validation selects.
   The test split is opened once, after the freeze.
7. **Assignment.** One recipe: partial-quantization probability 0.1 and
   assignment every 64 steps. Only fully quantized snapshots count. Master
   weights are training state and are not a result.
8. **Dead codes.** Book length stays fixed. An entry with no assignment at a
   cadence step is reseeded from that arm's PCG32 stream, and the reseed is
   logged. Entries are not deleted and the book is not grown.
9. **Checkpoint.** Resume continues master weights, indices, the book or its
   seed, scales and optimizer moments. Re-assigning from scratch is a new run.
   The artifact at each cooldown end is the quantized container.
10. **Generator.** The ADR 0013 PCG32 recipe: sum twelve unsigned 16-bit draws,
    subtract 393210, divide by 65536, and round to fp16. A fixed book and a
    learned book start from the same seed. A fixed book stores the seed and the
    generator identity. A learned book stores its fp16 entries once.
11. **F1 and F1-abl.** F1 requires the best vector mean val bpb to be lower
    than the best scalar mean by at least `max(0.02, 2σ)`, and lower at T and
    at 2T as well. F1-abl compares learned VQ with VQ-seed at the same G and
    rate, book bytes included; the prior is that the seed arm is at least as
    good. Both comparisons use eligible validation repairs only.
12. **Freeze and test.** Freeze the selected artifact hashes, then run
    `--final-test` once. A second test is not a revision of the first.
13. **Compute.** ADR 0004 still places this pilot on CPU. ADR 0009 moved only
    E0 off that rule. An Xbox vector executor may replace the CPU only after
    it matches the CPU oracle on identical inputs and identical artifact bytes.
    A scalar throughput number does not qualify it. No rented GPU.
14. **Accounting and byte order.** The file that parity reads is one FLP2
    artifact. No side file counts. `VQF1` stays the functional fixture. The
    framing is `FLP2`, u16 header length, canonical `GPTConfig` JSON, u32
    shared length, the shared section, then each tensor in `tensor_shapes()`
    order.

    A scalar arm keeps `core_fmt` `ternary` or `2bit` and an empty shared
    section. A vector arm uses the same JSON keys. Its `core_fmt` is `vq`,
    `emb_fmt` stays `4bit`, and `scale_policy` stays `row8log`. `delta` remains
    in the header and the vector core does not read it. `GPTConfig` gains no
    field. The embedding record stays the scalar 4-bit record. Norms stay raw
    fp16.

    The shared section holds one `VQB1` book, once: `VQB1`, u8 dimension, u8
    bits, u8 generator, u8 learned, u64 little-endian seed, then learned
    entries. The generator is 1. Dimension is 8 or 16. Bits are
    `dimension * rate` for rate 0.5 or 0.75. Learned is 0 or 1. A fixed book
    ends after those 16 header bytes. A learned book appends
    `2^bits * dimension` little-endian fp16 entries, level-major. The seed is
    that u64.

    A core vector record is the `row8log` scale bytes of a 2-bit scalar codec,
    an fp16 base plus one code byte per row, then a u32 byte length, then
    `rans.encode_best` of the group indices. The index count is
    `rows * ceil(cols / dimension)`, row-major, after the column axis is
    padded with zeros to a multiple of `dimension`. The alphabet is `2^bits`.
    Decode drops the padded columns.

This acceptance authorizes the host implementation of the decisions above.
It does not open a campaign, reserve a final test, or dispatch a console job.

## Consequences

`c58a86`, `766d4b` and `87686a` stay stopped. No further scalar campaign is
opened to name one format. The
[book-budget notes](proposals/e1-1-16-book-budget.md) stay a proposal; this
ADR cites their fit table and does not accept that file. A 4096-entry G=16
book cannot be added afterwards as the 1/16 learned arm. The six ADR 0013
snapping pairs are not a validation search.

Current host code is not this format. `core_fmt` `vq` is still rejected, a
nonempty FLP2 shared section is still rejected, and `VQF1` remains the
fixture. The next engineering step is to implement decisions 13 and 14 in the
host, with the CPU oracle as the numerical reference. The pilot runs only
after that implementation exists. An Xbox executor, if later written, is
qualified against that oracle before it replaces the CPU.

## Alternatives

Leaving the rules in the proposal was rejected: issue #25 requires an ADR that
names the selection hash. Training every allowed G as a search was rejected
because G=16 at rate 0.75 does not fit and because choosing G after validation
is a second comparison. Treating the ADR 0013 canaries as the scientific
ranking was already rejected by that ADR. Naming one scalar format from the
inside-gate paired result was rejected by the gate 4 review.

## Later (2026-10-11, host training)

Commit `b362991` stores one `VQB1` book in the FLP2 shared section. The host
trainer applies decisions 7–9. A vq core assigns every 64 steps and trains at
partial-quantization probability 0.1. Resume keeps the master weights, indices,
scales, book, and optimizer moments. The cooldown artifact is the quantized
FLP2 container of that held assignment. A learned book reseeds an unassigned
entry from the PCG32 stream that continues after the initial draws, and the
reseed is logged. A fixed book logs the same event and does not rewrite its
entries: the file stores the seed, and a rewritten entry would not round-trip.
The pilot has not started. No console job is authorized. This note does not
change the decision.
